# UAsset Demo

Minimal HTML + CSS + JS demo for `uasset.signaturesi.com`.

## Run
Just open `index.html` in a browser.

For local development:
- VS Code + Live Server, or
- any static server.

## Included
- Minimal responsive UAsset homepage
- SVG icon library
- Category filtering
- Search
- Icon detail modal
- Copy SVG
- Download SVG
- Mock Bean ID login using localStorage
- Collection and Pro placeholders

## Next backend step
Replace the mock login handler in `js/app.js` with the real Bean ID authentication API.
Do not put service-role or server secrets in the browser.
